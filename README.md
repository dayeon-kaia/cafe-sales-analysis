# Cafe Sales Analysis

카페 아르바이트 중 시간대와 날씨에 따라 잘 팔리는 메뉴가 다르다고 느낀 관찰을 공개 데이터로 검증하는 프로젝트

## 가설
- H1 출근 시간대(7~10시)에 커피 음료 비중이 다른 시간대보다 높다
- H2 점심·저녁 시간대에 베이커리·디저트 비중이 높다
- H3 비 오는 날 달콤한 음료 비중이 높다

## 데이터
- 카페 거래 데이터: Kaggle Coffee Shop Sales (링크 추가 예정)
- 날씨 데이터: Meteostat
- 한계: 본인이 일한 카페가 아닌 공개 해외 매장 데이터
